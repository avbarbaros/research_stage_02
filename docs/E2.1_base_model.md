# E2.1-B — CoT from Scratch on the Base Model: Results

| | |
|---|---|
| **Stage** | 2 — Reasoning Methods in Language Models (ablation of [E2.1](E2.1_cot_from_scratch.md)) |
| **Model** | `Qwen/Qwen2.5-7B` (base, no instruction tuning; bfloat16, greedy decoding) |
| **Dataset** | GSM8K test split, the first 100 of the E2.1 questions (seed 42) |
| **Command** | `python e2_1_cot_from_scratch.py --model base --n_eval 100` |
| **Result file** | `outputs/e2_1_results_20261101_1601_base.json` |
| **Status** | ✅ Complete. Hypothesis from E2.1 §4.2 **not supported** on this model (§4) |

---

## 1. Question

E2.1 on Qwen2.5-7B-**Instruct** found zero-shot CoT ≈ few-shot CoT, while the original papers,
which used base models, report few-shot > zero-shot. The hypothesis was that **instruction
tuning removes the benefit of exemplars**. If so, the same model *without* instruction tuning
should show the papers' ordering:

```
direct  <  zero-shot CoT  <  few-shot CoT
```

## 2. Setup

The base model has no chat template, so prompts follow the original papers' plain-text format
(`e2_1.base_prompts` in [config.yaml](../config.yaml)):

| Condition | Prompt | Answer taken from |
|---|---|---|
| `direct` | Wei et al.'s standard prompting: the 8 Wei exemplars with answers only (`A: The answer is 6.`), then `Q: {q}\nA:` | trigger phrase |
| `zero_shot_cot` | Stage 1: `Q: {q}\nA: Let's think step by step.` → Stage 2: stage 1 + reasoning + `\nTherefore, the answer (arabic numerals) is` (Kojima et al.) | first number after the stage-2 trigger |
| `few_shot_cot` | the 8 hand-written exemplars as `Q: …\nA: …` blocks, then `Q: {q}\nA:` | trigger phrase / last number |
| `few_shot_cot_wei` | the 8 Wei et al. exemplars, same format | trigger phrase / last number |

- No system prompt. Greedy decoding with `repetition_penalty=1.0`.
- Generation stops at `\nQ:`, `\nQuestion:` or `\n[Question]` (see §5).
- All four conditions ran in one job, so the paired McNemar tests are included.

## 3. Results

| Condition | Accuracy | 95% CI (Wilson) | Correct / 100 | Extraction failures | Mean response (chars) | Wall time |
|---|---:|---:|---:|---:|---:|---:|
| `direct` | **28.0%** | [20.1, 37.5] | 28 | 0 | 17.6 | 4.3 min |
| `zero_shot_cot` | **82.0%** | [73.3, 88.3] | 82 | 0 | 293.5 | 16.3 min |
| `few_shot_cot_wei` | **85.0%** | [76.7, 90.7] | 85 | 0 | 302.0 | 14.3 min |
| `few_shot_cot` (hand-written) | **79.0%** | [70.0, 85.8] | 79 | 0 | 237.4 | 12.6 min |

**Paired tests against zero-shot CoT (exact McNemar, same 100 questions):**

| Condition | Δ vs zero-shot CoT | Only zero-shot ✓ | Only this ✓ | p |
|---|---:|---:|---:|---:|
| `direct` | −54.0 pp | 56 | 2 | < 0.001 |
| `few_shot_cot_wei` | +3.0 pp | 6 | 9 | 0.61 |
| `few_shot_cot` | −3.0 pp | 9 | 6 | 0.61 |

**Pipeline checks:** 0 extraction failures in 400 responses. For zero-shot CoT, the Kojima
stage-2 answer matches the answer stated in the reasoning on all 100 questions
(`stage2_vs_stage1_mismatches = 0`), so the extraction is not picking up stray numbers.

Observed ordering:

```
few_shot_cot_wei (85.0) ≈ zero_shot_cot (82.0) ≈ few_shot_cot (79.0)  ≫  direct (28.0)
```

## 4. Interpretation

### 4.1 The main effect replicates: reasoning ≫ direct

CoT raises accuracy from 28% to 79–85% (about 3×), with 56 questions solved only with reasoning
and 2 only without. The same effect as on the Instruct model, and as in Wei et al. (2022).

### 4.2 The hypothesis is not supported: no few-shot advantage on the base model either

The three CoT variants lie within ±3 pp of each other, with p = 0.61 for both few-shot
comparisons. The pattern matches the Instruct model: Wei exemplars slightly ahead,
hand-written exemplars slightly behind, all within noise. **Removing instruction tuning does
not bring back the few-shot advantage reported in the papers.**

This does **not** rule out the original explanation in general, because Qwen2.5-7B "base" is
not a clean base model. The run shows clear traces of instruction-style math data in its
pretraining:

- Zero-shot samples often end with `. The answer is: 52.` That is the answer format of
  MetaMathQA-style synthetic GSM8K data, not anything in our prompt.
- Zero-shot CoT works without any exemplars: the model writes a short, correct reasoning chain
  and ends with "The answer is N." on its own.

A model that already "knows" the GSM8K answer format gains little from being shown it. So the
better reading is: **for Qwen2.5, the exemplar benefit is already absorbed during pretraining,
before instruction tuning.** Testing the original hypothesis needs a base model with less
instruction-style pretraining data, for example `Mistral-7B-v0.1` or `Llama-2-7b-hf`.

### 4.3 Base vs. Instruct

Comparison with [E2.1](E2.1_cot_from_scratch.md) (Instruct, 300 questions; the base run's 100
questions are the first 100 of those 300):

| Condition | Base (n = 100) | Instruct (n = 300) | Base response length | Instruct response length |
|---|---:|---:|---:|---:|
| direct | 28.0% | 21.3% | 18 chars | 2 chars |
| zero-shot CoT | 82.0% | 90.3% | 294 chars | 838 chars |
| few-shot CoT (Wei) | 85.0% | 90.0% | 302 chars | 518 chars |
| few-shot CoT (hand-written) | 79.0% | 88.3% | 237 chars | 470 chars |

- Instruction tuning adds roughly **5–9 pp** to every CoT condition. The question sets differ,
  so treat this as indicative, not exact.
- Base-model reasoning is **2–3× shorter**: terse arithmetic chains, not the
  Instruct model's structured, step-numbered answers.
- The base model's higher direct score (28.0% vs 21.3%) comes from a different prompt
  (answer-only exemplars vs a one-line instruction), so it is not a fair comparison.

## 5. Prompt design notes

Two choices in the base-model prompts matter for any future base model:

- **Stop strings.** A base model has no end-of-turn token, so after answering it may continue
  the document with new, invented problems. Generation therefore stops at `\nQ:`,
  `\nQuestion:` and `\n[Question]`. As a cross-check, zero-shot CoT also records the answer
  stated in the reasoning (`pred_stage1`). In this run it matched the Kojima stage-2 answer on
  all 100 questions.
- **Answer-only exemplars for `direct`.** A base model does not reliably follow a one-line
  format instruction, so `direct` uses Wei et al.'s standard prompting: exemplars that show only
  the answer. The model follows this format exactly ("The answer is 50.").

## 6. Limitations

- n = 100: Wilson intervals are about ±8 pp wide, so differences below ~6 pp between the CoT
  variants cannot be resolved (the paired test is somewhat more sensitive).
- One base model, which (§4.2) is likely contaminated with instruction-style math data.
- The base vs. Instruct comparison in §4.3 uses different question sets and, for `direct`,
  different prompts.

## 7. What this result feeds into

- **E2.2-B:** the zero-shot CoT records here (82.0%) are the greedy reference for
  self-consistency on the base model.
- **Stage 3:** the conclusion from E2.1 stands: modern open models already reason step by step
  without exemplars, so zero-shot CoT is the fair baseline for multimodal CoT.
- **Open item:** rerun on a "cleaner" base model to separate "instruction tuning" from
  "instruction-style pretraining data".
