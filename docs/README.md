reasoning thesis roadmap. Each page states the roadmap's success criterion, the evidence that
it was met, the full numbers, and what the result means for later stages.

## Key takeaways so far

1. **Reasoning is necessary, and the prompt style barely matters.** Any CoT prompt gives about
   90%. On an instruction-tuned model, few-shot exemplars change response length (−40%), not
   accuracy. Zero-shot CoT is the fair baseline for Stage 3.
2. **Test-time scaling saturates early.** k = 8 captures 87% of the self-consistency gain.
3. **Sample agreement predicts correctness.** Questions where ≥ 80% of samples agree are 97.7%
   correct, and 70% of errors sit in the 13% of low-agreement questions. This is a signal for
   adaptive compute (thesis direction D6).
4. **Voting leaves 4.7 pp on the table.** The correct answer is among the 32 samples for 98.0%
   of questions, but voting picks it for only 93.3%. This is the headroom E2.4's verifiers
   target.
5. **Exemplars do not help Qwen2.5 even without instruction tuning.** The base model shows the
   same zero-shot ≈ few-shot pattern, most likely because its pretraining already contains
   instruction-style math data ([E2.1-B](E2.1_base_model.md)).
6. **Self-consistency helps the weaker model far more.** +16.2 pp over a single sample on the
   base model vs +4.2 pp on Instruct, closing most of the accuracy gap, at about 6× the
   tokens ([E2.2-B](E2.2_base_model.md)).
7. **Base models need different extraction.** They keep writing after the answer and invent
   new problems. Check raw responses before trusting a new model's accuracy.
